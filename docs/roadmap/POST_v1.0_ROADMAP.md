# AI Factory OS Post v1.0 Roadmap

## 목표

AI Factory OS v1.0 이후에는 OS 기반 개발이 아니라 AI Factory가 실제로 제품을 개발하는 구조를 구현합니다.

## v1.1 - Planning Agent 실작동

- 사용자 요청 분석
- 개발 계획 JSON 생성
- Task 자동 분해
- 우선순위 / 리스크 / 승인 필요 여부 판단

## v1.2 - Development Agent 실작동

- 개발 계획 기반 Python 코드 생성
- Product 폴더에 코드 반영
- WorkerResult 기록
- 변경 파일 목록 생성

## v1.3 - QA Agent 실작동

- 자동 테스트
- 품질 점수
- 실패 시 수정 요청
- Regression Report 생성

## v1.4 - Documentation Agent 실작동

- CHANGELOG 자동 작성
- Release Note 자동 작성
- Project Status 자동 업데이트
- 사용자 보고서 생성

## v1.5 - Approval Gate

- 사용자 승인 대기열
- 승인 / 반려
- 위험 작업 차단
- Release 승인 체계

## v1.6 - Dashboard MVP

- 진행 중 Task
- Agent 상태
- Worker 상태
- Approval Queue
- Product 현황
- Update 상태

## 장기 방향

- GitHub 자동 연동
- n8n 연동
- Product별 Knowledge Base
- Self Evolution Cycle
- 자동 Sprint 제안
