# AI Factory OS v1.7 Release Notes

## Release Type

Release Management MVP

## 핵심 추가 기능

- Release Engine 추가
- `release create` 명령 추가
- `release latest` 명령 추가
- `release list` 명령 추가
- 승인된 Approval 항목만 Release 생성 가능
- Release Manifest 생성
- Release Notes 생성
- CHANGELOG Draft 생성
- VERSION Candidate 생성
- Release Package ZIP 생성
- SHA256 생성
- Release History 저장

## 확인 명령

```powershell
python main.py approve approve
python main.py release create
python main.py release latest
python main.py release list
```
